# Maven Market Retail Analytics Dashboard

## Overview
This project is a retail analytics dashboard developed using Microsoft Power BI. The dashboard provides business insights related to sales transactions, profitability, product returns, and regional performance for a retail business named Maven Market.

The objective of this project is to transform raw retail data into meaningful business intelligence through interactive visualizations, KPI tracking, and trend analysis.

## Topline Performance Dashboard
- Current Month Transactions
- Current Month Profit
- Current Month Returns
- Weekly Revenue Trending
- Revenue vs Target
- Top Product Brand Analysis
- Geographic Revenue Distribution

---

# Business Problem
Retail organizations generate large volumes of transactional data across stores, products, customers, and regions. Without centralized analytics, businesses struggle to:

- Monitor overall business performance
- Identify top-performing products
- Analyze profitability trends
- Track return rates
- Compare regional sales performance
- Evaluate revenue targets

This dashboard solves these challenges by providing a centralized business intelligence solution using Power BI.

---

# Project Objectives

- Analyze monthly transaction and profit performance
